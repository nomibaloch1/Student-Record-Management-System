# 🎓 Student Record Management System

[![Run on OnlineGDB](https://img.shields.io/badge/Run%20C%2B%2B-OnlineGDB-blue?style=for-the-badge&logo=cplusplus)](https://www.onlinegdb.com/online_c++_compiler)

A beginner-friendly console-based Student Record Management System developed using **C++ and Object-Oriented Programming (OOP)**.

## ✨ Features

- ➕ Add New Student
- 📋 Display All Students
- 🔍 Search Student by Roll Number
- ✏️ Update Student Information
- 🗑️ Delete Student Record
- 💾 Automatically Save Student Records
- 📂 Load Saved Records
- ✅ Automatic Pass/Fail Result

## 📊 Passing Criteria

| Marks | Result |
|---|---|
| 50 or above | PASS |
| Below 50 | FAIL |

## 🛠️ Technologies Used

- C++
- Classes and Objects
- Encapsulation
- Constructors
- Vectors
- File Handling

## 🌐 Run Online

You can open an online C++ compiler using the badge above.

**Note:** Copy `main.cpp` into the online compiler to run the program. File storage may depend on the compiler environment.

## 💾 Data Storage

Student records are saved in `students.txt`.

The program automatically loads previously saved student records when it starts.

This project was created to practice basic C++ programming and Object-Oriented Programming concepts through a practical beginner-level application.
